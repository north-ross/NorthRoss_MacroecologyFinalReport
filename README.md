# MacroecologyFinalReport
 This repository contains the analysis script and dataset used in North Ross' final paper for EEB-310: Macroecology and Global Change, at the University of Helsinki. 
 
 ## MetaAnalysis
 
 The MetaAnalysis folder contains an .Rmd file that was used to preform the meta-analysis and create the plots used in the final report. It also contains a csv file "ExtractedData_2026-05-31.csv", the full dataset extracted from nine scientific papers.
 
 ## DataExtraction
 
 This data contains subfolders for each paper where data extraction was non-trivial and required some further analysis. This includes R scripts, LibreOffice spreadsheets and WebPlotDigitizer .tar project exports.
